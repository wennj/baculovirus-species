K2P-based species demarcation in Baculoviridae

Input data

This analysis uses the K2P distances already calculated in 04_substitution_patterns.qmd. No K2P distances are recalculated and no existing figures are overwritten.

Validation

expected_dimensions <- c(width = as.integer(8 * 300), height = as.integer(3 * 300))
png_dimensions <- function(path) {
  bytes <- readBin(path, what = "raw", n = 24L)
  if (length(bytes) < 24L || !identical(bytes[1:8], as.raw(c(137, 80, 78, 71, 13, 10, 26, 10)))) stop("Not a valid PNG file: ", path, call. = FALSE)
  c(width = sum(as.double(bytes[17:20]) * 256^(3:0)), height = sum(as.double(bytes[21:24]) * 256^(3:0)))
}
if (any(png_dimensions(full_histogram_path) != expected_dimensions) || any(png_dimensions(zoom_histogram_path) != expected_dimensions)) stop("The histogram PNG dimensions are incorrect.", call. = FALSE)
